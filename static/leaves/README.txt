YOUR OWN LEAF PICTURES GO HERE
==============================

Put image files in this folder and the landing page uses them instead of the drawn leaves:
falling leaves, the pile at the bottom, and the leaf that leaves the tree. Nothing else to
change. Reload the page (Ctrl+F5). Remove the files to go back to the drawn leaves.

Requirements
- Format: PNG or WebP with a TRANSPARENT background (SVG also works). JPG will not work:
  it has a white box around the leaf.
- Cropped tight to the leaf, with no empty margin.
- Leaf upright, stem pointing down. Each leaf is rotated randomly on the page.
- About 256 to 600 px on the longest side. Larger files only slow the page down.
- 3 to 8 different leaves look natural: different shapes and colours (red, orange, yellow, brown).
- Keep each file under ~150 KB.

File names do not matter, but the list is read in alphabetical order.
Only use pictures you took yourself or that you are allowed to use (check the licence).
